### Dataset
For the fine-tuning with LoRA the HUI-Audio-Corpus-German dataset[^4] is used (https://opendata.iisys.de/dataset/hui-audio-corpus-german/). The dataset is assembled from voices of multiple speakers and contains normalized and noise-suppressed audio data with a high sample rate and corresponding transcripts. For the training process only one speaker subset is used.
